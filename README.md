# Calculator

Full-stack calculator built as a React + TypeScript single-page application backed by a Go REST microservice that performs exact decimal arithmetic.

## Repository layout

| Path | Contents |
|---|---|
| `backend/` | `calculator-service`, the Go REST microservice |
| `frontend/` | React + TypeScript web client |
| `docs/` | Architecture, business rules, API contract and architecture decision records |
